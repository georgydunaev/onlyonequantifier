# onlyonequantifier — Minimal Intuitionistic First-Order Logic (`my_IFOL.thy`)

## Overview
`onlyonequantifier` explores a minimal formulation of Intuitionistic First-Order Logic in Isabelle/Pure (`my_IFOL.thy`), examining quantifier definability and minimal logical primitives.
